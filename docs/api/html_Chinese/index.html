STTNet 中文入门手册与 API 参考

轻量、直接、面向 Linux 服务端的 C++17 网络框架

STTNet 基于 epoll 与 Reactor 事件驱动模型，提供 TCP、UDP、HTTP/1.1、WebSocket，以及 TLS、HTTPS、WSS 支持。框架把连接管理、协议解析、事件循环和并发调度封装起来，业务代码主要围绕回调编写。

适合轻量 API 服务、实时通信服务、网关、IoT 接入、游戏服务端和需要嵌入现有 C++ 项目的网络模块。

快速开始 HTTP Demo WebSocket Demo API 参考 English 返回语言入口

轻量易嵌入

核心使用 C++17，接口集中在 sttnet.h，可通过 CMake 安装、add_subdirectory 或直接集成到现有工程。

高并发网络模型

基于 epoll、非阻塞 I/O 和 one-loop-per-thread Reactor，支持多事件循环、WorkerPool、发送队列与慢连接背压。

常用协议齐全

统一覆盖 TCP、UDP、HTTP、WebSocket 和对应加密通信，并提供 JSON、日志、文件、信号及常用服务端工具。

性能说明：旧版本曾在 4 核 4G 小型开发板上记录约 6.5 万请求/秒、平均 2–3 ms。该数据属于历史案例，不代表所有机器或当前版本的固定结果；实际性能应以目标 Linux 环境中的 benchmark 为准。

快速开始

下面以 Ubuntu / Debian 为例，从下载源码到启动第一个 HTTP 服务可以直接按顺序执行。

1. 安装依赖

sudo apt-get update
sudo apt-get install -y build-essential cmake pkg-config libjsoncpp-dev libssl-dev

2. 下载并构建

git clone https://github.com/StephenTaam/STTNet.git
cd STTNet
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
  -DSTTNET_BUILD_EXAMPLE=ON \
  -DSTTNET_BUILD_TESTS=OFF \
  -DSTTNET_BUILD_BENCHMARK=OFF
cmake --build build --parallel

3. 启动示例

./build/examples/sttnet_http_hello

看到监听提示后，在另一个终端执行：

curl -i http://127.0.0.1:8080/ping

返回正文 pong 即表示服务运行成功。按 Ctrl-C 可触发优雅退出。

接入自己的 CMake 项目

将 STTNet 放入项目目录时：

set(STTNET_BUILD_EXAMPLE OFF CACHE BOOL "" FORCE)
set(STTNET_BUILD_TESTS OFF CACHE BOOL "" FORCE)
add_subdirectory(third_party/STTNet)

target_link_libraries(my_server PRIVATE STTNet::sttnet)

使用已安装的 STTNet 时：

find_package(STTNet 0.7 CONFIG REQUIRED)
target_link_libraries(my_server PRIVATE STTNet::sttnet)

业务代码统一包含：

#include <sttnet.h>

最小 HTTP 服务

下面的程序注册 /ping 路由并返回 pong：

#include <sttnet.h>

using namespace stt::network;
using stt::system::ServerSetting;

int main()
{
    if (!ServerSetting::blockTerminationSignals())
        return 1;

    HttpServer server;

    server.setFunction("/ping",
        [](HttpServerFDHandler &client,
           HttpRequestInformation &request) {
            (void)request;
            return client.sendText("pong") ? 1 : -2;
        });

    if (!server.startListen(8080))
        return 2;

    ServerSetting::waitForTerminationSignal();
    return server.close() ? 0 : 3;
}

编译并启动后，可访问 http://127.0.0.1:8080/ping，或使用：

curl http://127.0.0.1:8080/ping

读取请求与返回 JSON

server.setFunction("/user",
    [](HttpServerFDHandler &client,
       HttpRequestInformation &request) {
        auto contentType = request.headerValue("content-type");
        auto body = request.bodyView();

        Json::Value result;
        result["ok"] = true;
        result["content_type"] = contentType;
        result["body_size"] = static_cast<Json::UInt64>(body.size());

        return client.sendJson(result) ? 1 : -2;
    });

最小 WebSocket Echo 服务

#include <sttnet.h>

using namespace stt::network;
using stt::system::ServerSetting;

int main()
{
    if (!ServerSetting::blockTerminationSignals())
        return 1;

    WebSocketServer server;

    server.setGlobalSolveFunction(
        [](WebSocketServerFDHandler &client,
           WebSocketFDInformation &message) {
            return client.sendMessage(message.message);
        });

    if (!server.startListen(5050))
        return 2;

    ServerSetting::waitForTerminationSignal();
    return server.close() ? 0 : 3;
}

客户端连接 ws://127.0.0.1:5050 后，服务端会原样返回收到的文本消息。HTTPS/WSS 可通过服务器的 TLS 配置接口加载证书与私钥。

并发与生产配置

网络 I/O 由 Reactor 线程处理；耗时业务可投递到 WorkerPool，避免阻塞事件循环。每个连接可设置待发送数据高水位，慢客户端达到限制后会触发背压，防止发送队列无限增长。

ServerSocketOptions options;
options.tcp_no_delay = true;
options.keep_alive = true;
options.listen_backlog = 4096;

server.setSocketOptions(options);
server.setMaxPendingWriteBytes(4 * 1024 * 1024);
server.setGracefulShutdownTimeout(5000);

// HTTPS / WSS
// server.setTLS("server.crt", "server.key");
信号处理：blockTerminationSignals() 应在 Reactor 或 Worker 线程创建前调用。正常退出可等待在途请求和发送队列完成；SIGKILL 无法被程序捕获，因此不能执行优雅退出。
