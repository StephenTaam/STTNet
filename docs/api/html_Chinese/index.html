最小 HTTP 服务

第一次使用可以先看懂下面的主线，再进入详细指导手册逐步拆解。

#include <sttnet.h>

int main()
{
    using namespace stt::network;
    using stt::system::ServerSetting;

    // 必须在 Reactor / Worker 线程创建前阻塞退出信号。
    if(!ServerSetting::blockTerminationSignals())
        return 1;

    // 创建 HTTP 服务对象。
    HttpServer server;

    // 注册 /ping 路由。发送成功返回 1，失败返回 -2 并关闭连接。
    server.setFunction("/ping",
        [](HttpServerFDHandler &client, HttpRequestInformation &) {
            return client.sendText("pong") ? 1 : -2;
        });

    // 开始监听 8080 端口。
    if(!server.startListen(8080))
        return 2;

    // 主线程同步等待 Ctrl-C 或 SIGTERM。
    ServerSetting::waitForTerminationSignal();

    // 在正常线程上下文中优雅关闭。
    return server.close() ? 0 : 3;
}
继续学习：指导手册会解释为什么要先阻塞信号、回调参数是什么、为什么返回 1/0/-1/-2、什么时候必须使用 WorkerPool，以及生产参数应该怎样设置。
