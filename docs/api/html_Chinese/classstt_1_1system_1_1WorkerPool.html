详细描述

固定大小的工作线程池

WorkerPool 内部维护一个任务队列和若干工作线程。 每个工作线程循环从队列中取出任务并执行。

特性

  • 固定线程数量
  • 线程安全的任务提交
  • 支持优雅停止（graceful shutdown）

线程安全说明

  • submit() 是线程安全的
  • stop() 是线程安全的

使用示例

WorkerPool pool(4);
pool.submit([] {
// 执行任务
});
pool.stop();

◆ stop()

void stt::system::WorkerPool::stop ( const bool drain = true)
inline

停止线程池并等待所有线程退出

参数
draintrue：执行完已排队任务；false：丢弃尚未开始的任务，仅等待正在执行的任务返回。

调用后：

  • 不应再提交新的任务
  • drain=true 时执行完已排队任务；drain=false 时丢弃尚未开始的任务
  • 所有工作线程都会退出并 join

该函数可安全重复调用。

true：任务已提交；false：线程池已停止或等待队列已满，任务未入队。
注解
