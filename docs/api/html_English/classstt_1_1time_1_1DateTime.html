Detailed Description

A local wall-clock text utility and a monotonic timer backed by steady_clock.

Usage boundaries:
  • getTime() produces local text, not a Unix timestamp. ISO8086A/B are historical macro names and carry no timezone.
  • convertFormat() rearranges text according to declared tokens; it is not a general date parser.
  • checkTime(), endTiming(), and getDt() all return stt::time::Duration.
  • Timing before startTiming(), invalid dates, and reverse subtraction produce an invalid Duration.
