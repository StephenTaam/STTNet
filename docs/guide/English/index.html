STTNet Programming Guide

A complete chapter-by-chapter path from installation to HTTP, WebSocket, TCP, UDP, clients, TLS, and production operation.

This guide is a learning path, not a list of method names. Read it in order on your first project, or jump directly to a protocol chapter when you already understand event-driven network servers.

WebSocketHandshake validation, frames, heartbeat, and WSS. TCP / UDPByte streams, datagrams, framing, and custom protocols. ClientsHTTP, WebSocket, TCP, and UDP clients. SignalsSafe SIGINT/SIGTERM handling and cleanup. Production settingsLogging, sockets, bounds, limits, metrics, timeouts. Commented demosEleven buildable, verifiable repository examples.
