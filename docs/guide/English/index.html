STTNet Programming Guide

Learn by domain: run first, then understand; use the guide to learn, and the API reference to look up complete signatures.

STTNet is more than network servers. Its public capabilities are distributed across the stt::network, stt::data, stt::time, stt::file, stt::security, and stt::system namespaces. This guide reorganizes them by use case so users do not have to infer intent from a class list.
