Chapter 13: Time, Duration, and Timing

Choose wall-clock and monotonic time correctly for formats, intervals, comparison, and latency.

1. Separate wall-clock time from duration

DateTime formats time text and measures elapsed work. Duration represents an interval. Logs and certificate dates use wall-clock time; timeouts and latency use a monotonic clock.

2. Current time and format conversion

std::string now;
DateTime::getTime(now, "yyyy-mm-ddThh:mi:ss.sss");

std::string display = now;
DateTime::convertFormat(
    display,
    "yyyy-mm-ddThh:mi:ss.sss",
    "yyyy/mm/dd hh:mi:ss.sss");

Placeholders are yyyy mm dd hh mi ss sss. Minutes use mi to avoid colliding with month mm.

3. Measure elapsed time

DateTime timer;
timer.startTiming();

Duration current = timer.checkTime(); // Read without stopping.
Duration total = timer.endTiming();   // Stop and return elapsed time.
std::cout << total.convertToMsec() << " ms
";

The timing API uses steady_clock, so NTP or manual clock changes do not distort elapsed durations. Calling checkTime() or endTiming() before startTiming() returns fields set to -1.

4. Duration conversion

Use convertToDay/Hour/Min/Sec/Msec for a single unit and recoverForm() to expand milliseconds into fields. Comparison and arithmetic operators are useful for timeout policies.

Do not use formatted wall-clock text for request deadlines. Do not use a monotonic clock as a public timestamp.
