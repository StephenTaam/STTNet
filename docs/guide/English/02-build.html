Chapter 2: Download, Build, Run

Complete the full path from dependencies and cloning to build, launch, and curl verification.

1. Install dependencies

sudo apt-get update
sudo apt-get install -y build-essential cmake pkg-config libjsoncpp-dev libssl-dev

2. Clone the repository

git clone https://github.com/StephenTaam/STTNet.git
cd STTNet

3. Configure and build

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
  -DSTTNET_BUILD_EXAMPLE=ON \
  -DSTTNET_BUILD_TESTS=OFF \
  -DSTTNET_BUILD_BENCHMARK=OFF
cmake --build build --parallel

4. Run and verify

./build/examples/sttnet_http_hello
# In another terminal:
curl -i http://127.0.0.1:8080/ping
Expected: HTTP 200 with body pong. Press Ctrl-C and verify a clean exit.

5. Common failures

SymptomCheck
json/json.h not foundInstall libjsoncpp-dev and reconfigure a clean build directory.
OpenSSL not foundInstall libssl-dev and confirm the correct architecture is selected.
Bind failedCheck that the port is free; avoid privileged ports as an unprivileged user.
Built but cannot startInspect stderr/logs and verify certificate, permission, port, and fd settings.

6. Link STTNet into your CMake project

add_subdirectory(third_party/STTNet)
add_executable(my_server main.cpp)
target_link_libraries(my_server PRIVATE STTNet::sttnet)
