Chapter 12: JSON Parsing and Generation

Separate HTTP body handling from JSON parsing, validation, and generation.

1. JSON has two separate layers

The HTTP layer receives request bytes and sends responses. JsonCpp and stt::data::JsonHelper parse and generate JSON. A successful bodyView() does not mean the body is valid JSON.

ToolPurposeBest use
Json::ValueBuild and inspect objects and arraysStructured JSON; preferred approach
JsonHelper::toStringCompact serializationHTTP responses and structured log fields
toJsonArrayParse text into Json::ValueSimple trusted-input paths
getValueExtract one field or array itemSmall lookups
createJson/createArrayCreate small flat valuesTiny responses, not complex nesting

2. Recommended server-side parsing

Json::CharReaderBuilder builder;
Json::Value root;
std::string errors;
std::istringstream input(std::string(request.bodyView()));

// Invalid syntax is a client input error; stop before reading fields.
if(!Json::parseFromStream(builder, input, &root, &errors))
    return client.sendText("invalid json", "400 Bad Request") ? -1 : -2;

if(!root.isMember("name") || !root["name"].isString())
    return client.sendText("name is required", "422 Unprocessable Entity") ? -1 : -2;

Json::Value response;
response["ok"] = true;
response["name"] = root["name"];
return client.sendJson(response, "201 Created") ? 1 : -2;

3. JsonHelper example

Json::Value user;
user["id"] = 1001;
user["name"] = "Stephen";
user["roles"].append("developer");

const std::string text = stt::data::JsonHelper::toString(user);
const Json::Value parsed = stt::data::JsonHelper::toJsonArray(text);
std::cout << parsed["name"].asString() << std::endl;

4. Return values and boundaries

  • getValue() returns -1 on failure, 0 for a scalar, and 1 for an object or array.
  • toJsonArray() reports parse errors to stderr and returns an empty value. In a server endpoint, use Json::parseFromStream when you need a controlled error response.
  • Check JSON types before calling accessors.
  • Set body-size limits before parsing untrusted JSON.
Do not concatenate JSON manually. Quotes, backslashes, control characters, and Unicode require escaping.
