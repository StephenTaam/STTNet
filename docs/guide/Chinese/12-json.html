第 12 章：JSON 解析与生成

区分 HTTP 请求体与 JSON 解析，正确生成、验证和返回结构化数据。

1. JSON 在 STTNet 中分两层

HTTP 层负责接收请求体和发送响应；JSON 层由 JsonCpp 与 stt::data::JsonHelper 负责。不要把二者混成一个概念：bodyView() 给你原始字节，解析是否成功仍需业务代码判断。

工具用途适合场景
Json::Value构造、读取对象和数组结构化 JSON，推荐优先使用
JsonHelper::toString紧凑序列化HTTP JSON 响应、日志字段
toJsonArray把文本解析为 Json::Value已确认输入合法、能接受错误输出到 stderr 的简单场景
getValue快速提取字段或数组元素简单读取；复杂结构仍建议使用 Json::Value
createJson/createArray快速创建扁平对象/数组小型响应；嵌套结构不建议用递归拼接

2. 推荐写法：显式解析并处理错误

Json::CharReaderBuilder builder;
Json::Value root;
std::string errors;
std::istringstream input(std::string(request.bodyView()));

// 解析失败是客户端输入错误，应返回 400，而不是继续读取字段。
if(!Json::parseFromStream(builder, input, &root, &errors))
    return client.sendText("invalid json", "400 Bad Request") ? -1 : -2;

// 业务字段缺失与 JSON 语法错误不同，可单独返回 422 或 400。
if(!root.isMember("name") || !root["name"].isString())
    return client.sendText("name is required", "422 Unprocessable Entity") ? -1 : -2;

Json::Value response;
response["ok"] = true;
response["name"] = root["name"];
return client.sendJson(response, "201 Created") ? 1 : -2;

3. JsonHelper Demo

Json::Value user;
user["id"] = 1001;
user["name"] = "Stephen";
user["roles"].append("developer");

// 序列化为紧凑 JSON 文本。
const std::string text = stt::data::JsonHelper::toString(user);

// 再解析回 Json::Value。
const Json::Value parsed = stt::data::JsonHelper::toJsonArray(text);
std::cout << parsed["name"].asString() << std::endl;

4. 返回值与边界

  • getValue()：-1 表示失败，0 表示普通值，1 表示对象或数组。
  • toJsonArray() 解析失败时会输出错误并返回空值；服务端接口更建议使用 Json::parseFromStream 自己控制错误响应。
  • 整数、布尔值、字符串不要一律调用 asString()；应先检查类型。
  • 设置请求体上限，避免攻击者提交超大 JSON 消耗内存和 CPU。
不要手工拼 JSON。字符串中的引号、反斜杠和 Unicode 都需要转义。优先构造 Json::Value，再统一序列化。
