第 12 章：JSON 解析与生成

HTTP body 是原始字节，JsonCpp 负责解析，JsonHelper 只提供若干便利封装。

1. 先区分 HTTP 与 JSON

request.bodyView() 返回请求体视图，不会自动确认它是 JSON。业务代码必须检查 Content-Type、请求体大小、解析结果和字段类型。

2. 服务端推荐显式解析

Json::CharReaderBuilder builder;
Json::Value input;
std::string errors;

// bodyView() 是非拥有视图；本例在当前回调中立即解析。
const std::string_view body = request.bodyView();
std::unique_ptr<Json::CharReader> reader(builder.newCharReader());
if(!reader->parse(body.data(), body.data() + body.size(), &input, &errors))
    return client.sendText("invalid json", "400 Bad Request") ? -1 : -2;

if(!input.isMember("name") || !input["name"].isString())
    return client.sendText("name is required", "422 Unprocessable Entity") ? -1 : -2;

3. JsonHelper 的真实契约

API行为失败/边界
toString(Value)序列化为紧凑 JSON 文本字符串值会带 JSON 引号
toJsonArray(text)解析为 Json::Value失败时输出错误并返回空 Value；服务端通常应自己解析以控制响应
createJson(...)按 key/value 对创建扁平对象参数必须成对；布尔值保持 JSON bool，不转成整数
createArray(...)创建数组复杂嵌套结构优先直接操作 Json::Value
jsonAdd(a,b)对象合并成员；数组追加元素解析失败或对象/数组类型混用时返回空字符串
getValue()提取字段或数组元素-1 失败，0 标量，1 对象/数组

4. 类型不要猜

const std::string text = stt::data::JsonHelper::createJson(
    "ok", true,
    "count", 3,
    "message", "ready");

Json::Value value = stt::data::JsonHelper::toJsonArray(text);
if(value.isObject() && value["ok"].isBool())
    std::cout << value["ok"].asBool() << '
';
不要手工拼 JSON。字符串转义、Unicode、数字和布尔类型都容易写错。设置请求体上限，并在读取字段前检查对象结构与类型。
