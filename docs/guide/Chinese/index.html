STTNet 编程指导手册

按领域分类学习：先运行，再理解；先用指导手册学会写，再用 API 参考查完整签名。

STTNet 不只有网络服务端。完整公开能力分布在 stt::network、stt::data、stt::time、stt::file、stt::security 和 stt::system 六个命名空间中。本手册把它们按使用场景重新组织，避免用户只能在类列表里猜用途。

基础先理解运行模型，再完成下载、依赖安装和构建。网络服务与客户端HTTP、WebSocket、TCP、UDP、客户端、TLS 和 WorkerPool。数据与工具类JSON、时间、文件、异步日志、编码、加密和数值工具。信息安全连接限流、黑名单、输入边界、TLS 与安全设计原则。系统与进程Linux 信号、系统初始化、服务设置、进程守护和心跳。生产部署接入现有项目、资源限制、监控和上线检查。完整注释 Demo19 个可构建示例，包含运行命令、验证方法和预期结果。
推荐方式：第一次使用先读第 1、2、3 章；需要某项能力时进入对应分类；已经知道类名时直接查 API。
