STTNet 编程指导手册

从安装到生产部署，逐章理解并写出 HTTP、WebSocket、TCP、UDP、客户端和 TLS 程序。

这套手册不是 API 名称列表，而是一条可以跟着做的学习路径。建议第一次使用时按章节顺序阅读；已经熟悉网络编程时，可以直接跳到对应协议章节。

先理解运行模型Reactor、Handler、请求对象、WorkerPool 和所有权。 HTTP 入门从 /ping 到 JSON、路由和错误处理。 阻塞任务把数据库、文件和 RPC 移出 Reactor。 WebSocket握手检查、文本/二进制帧、心跳和 WSS。 TCP / UDP理解字节流、报文边界和自定义协议。 客户端HTTP、WebSocket、TCP 和 UDP 客户端。 信号与退出SIGINT、SIGTERM、SIGPIPE 和安全清理。 生产配置日志、Socket、背压、限流、指标和超时。 完整注释 Demo11 个与仓库同步、可构建、可验证的示例。 API 参考知道要用哪个类后，再查询签名和全部成员。
阅读方式：指导手册解释为什么这样写；Demo 给出完整程序；API 参考负责查所有方法。三者各司其职。
