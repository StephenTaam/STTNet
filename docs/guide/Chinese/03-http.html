第 3 章：第一个 HTTP 服务

写出 /ping，理解服务对象、路由、Handler、请求对象和返回值约定。

1. 完整程序

#include <sttnet.h>
#include <iostream>

int main()
{
    using namespace stt::network;
    using stt::system::ServerSetting;

    // 必须在线程创建前阻塞退出信号。
    if(!ServerSetting::blockTerminationSignals())
        return 1;

    HttpServer server;

    server.setFunction("/ping",
        [](HttpServerFDHandler &client, HttpRequestInformation &) {
            // 1：本阶段成功；-2：发送失败并关闭连接。
            return client.sendText("pong") ? 1 : -2;
        });

    if(!server.startListen(8080))
        return 2;

    std::cout << "http://127.0.0.1:8080/ping\n";
    ServerSetting::waitForTerminationSignal();
    return server.close() ? 0 : 3;
}

2. 一行一行理解

  1. blockTerminationSignals() 必须在线程创建前调用，为后面的安全退出做好准备。
  2. 构造 HttpServer。默认开启安全模块，并创建合理的连接、接收和队列上限。
  3. setFunction("/ping", ...) 注册 path 路由。默认路由 key 是 request.loc。
  4. Handler 负责当前连接的发送操作，请求对象保存 method、path、header 和 body。
  5. startListen(8080) 启动监听和 Reactor。返回 false 时不要继续假装服务已经启动。
  6. 主线程等待 SIGINT/SIGTERM，然后在正常线程上下文中调用 server.close()。

3. 回调返回值概览

值准确含义
1当前阶段成功；如果同一路由还有后续阶段，继续执行下一阶段。
0当前阶段已交给 WorkerPool；Worker 完成后从下一阶段继续。
-1停止本次请求/消息的后续阶段，但不主动要求关闭连接。
-2停止处理并要求关闭连接。
这些值是 STTNet 的流程控制，不是 HTTP 状态码。HTTP 404 要通过 sendText(..., "404 Not Found") 或 sendJson() 发送，不能 return 404。

4. 路由找不到时

server.setGlobalSolveFunction(
    [](HttpServerFDHandler &client, HttpRequestInformation &) {
        return client.sendText("not found", "404 Not Found") ? 1 : -2;
    });
