第 13 章：时间、时间间隔与计时

正确选择墙上时间与单调时间，处理格式、间隔、比较和性能计时。

1. 绝对时间与持续时间要分开

DateTime 处理时间文本、格式转换和计时；Duration 表示两个时间点之间的间隔。日志时间、证书日期属于绝对时间；请求耗时、重试间隔属于持续时间。

2. 获取和格式化当前时间

std::string now;
// 带毫秒的格式，便于日志和性能排查。
stt::time::DateTime::getTime(now, "yyyy-mm-ddThh:mi:ss.sss");

std::string display = now;
stt::time::DateTime::convertFormat(
    display,
    "yyyy-mm-ddThh:mi:ss.sss",
    "yyyy/mm/dd hh:mi:ss.sss");

格式占位符为 yyyy mm dd hh mi ss sss。mi 表示分钟，避免与月份 mm 冲突。格式字符串必须和输入文本位置对应。

3. 用 steady clock 测量耗时

stt::time::DateTime timer;
timer.startTiming();

// 执行业务操作……
stt::time::Duration current = timer.checkTime(); // 查看但不停止
stt::time::Duration total = timer.endTiming();   // 停止并返回总耗时
std::cout << total.convertToMsec() << " ms
";

startTiming/checkTime/endTiming 内部使用单调时钟，系统时间被 NTP 调整时不会让耗时倒退。未开始就调用 checkTime/endTiming 会返回字段为 -1 的结果。

4. Duration 的单位转换

convertToDay/Hour/Min/Sec/Msec 用于把组合字段转成统一单位；recoverForm() 可把毫秒恢复为日、时、分、秒、毫秒。比较和加减运算适合超时配置与统计。

墙上时间不能替代单调时间。不要用格式化日期计算请求超时；不要用单调时钟生成对外时间戳。两种时间各有职责。
